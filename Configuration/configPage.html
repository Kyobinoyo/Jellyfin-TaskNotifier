Home Assistant Task Notifier

While a tracked scheduled task (e.g. "Scan Media Library") is running, the sensor below is set to on in Home Assistant. It goes back to off once no tracked task is running anymore — use its state changes as an automation trigger.

Create one in Home Assistant under your profile → Security → Long-Lived Access Tokens.
This entity is created/updated automatically via the Home Assistant REST API — no need to define it in Home Assistant first.
Leave empty to track every scheduled task. To only track specific ones, enter their task keys, e.g. RefreshLibrary for "Scan Media Library". Task names/keys are listed under Dashboard → Scheduled Tasks.
Useful if you want automations per specific task instead of the shared running/idle sensor above.
Enable only if your Home Assistant URL uses HTTPS with a self-signed certificate.
